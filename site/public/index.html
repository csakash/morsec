Questions
01Does morsec send my secrets anywhere?

No. Keys stay in your Mac's keychain and only go where you allow.

02Which agents does it work with?

Claude Code and Codex today, plus any MCP client. Cursor and Gemini are next.

03What if the agent edits its settings to skip morsec?

Nothing leaks: it never had a key. It just loses access.

04What happens when msd isn't running?

Nothing goes out. morsec fails closed.
