# csakash/tap

Homebrew tap for [morsec](https://github.com/csakash/morsec): coding agents use your secrets
without seeing them.

```bash
brew install csakash/tap/morsec
ms --version
ms init
```

`ms` is also installed as `mors`. Apple silicon, macOS 13 or later.

The formula installs prebuilt binaries, signed with Developer ID and notarized. Every release
has a CycloneDX SBOM and minisign-signed checksums; the formula installs the SBOM and the
build record to `$(brew --prefix)/share/morsec/`. morsec has no auto-update: upgrade with
`brew upgrade morsec`.

This repository is generated by `scripts/release.sh` in the morsec repository
(`packaging/homebrew/`). Don't edit `Formula/morsec.rb` here by hand.
